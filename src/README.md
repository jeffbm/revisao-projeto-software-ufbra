# Implementação do Sistema

A implementação do projeto será realizada após a conclusão da 6ª aula.

Até este momento, o foco do trabalho está em:

- identificação do problema;
- definição dos requisitos;
- delimitação do escopo;
- arquitetura do sistema;
- modelagem UML;
- documentação;
- controle de versão.

Após a 6ª aula, durante a revisão geral para a prova final, o projeto será retomado para demonstrar a passagem do **projeto para a implementação**.

Nesse momento serão criados e analisados os arquivos:

```text
index.html
app.js
```

A implementação deverá respeitar os requisitos e modelos definidos anteriormente.

Qualquer alteração necessária no projeto durante a implementação deverá ser documentada e justificada.
