# UML — Fontes PlantUML

Os arquivos desta pasta utilizam a sintaxe PlantUML para representar diagramas UML.

## Diagramas

- `casos-de-uso.puml`
- `classes.puml`
- `sequencia-abrir-os.puml`
- `sequencia-fechar-os.puml`
- `sequencia-agendar.puml`
- `estados-os.puml`
- `componentes.puml`
- `atividade-fechar-os.puml`

## Uso no VS Code

Uma forma simples de visualizar é instalar uma extensão compatível com PlantUML e abrir o preview do arquivo `.puml`.

## Observação didática

PlantUML é a ferramenta de representação. Os elementos utilizados nos arquivos correspondem a diagramas UML: atores, casos de uso, classes, associações, sequências, estados, atividades e componentes.
